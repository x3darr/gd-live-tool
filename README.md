# 黎明图鉴 · gd-live-tool

恐怖黎明（Grim Dawn）本地资料查询工具：装备/词缀/怪物/技能/星座速查 + OBS 叠加层 + 直播切片打点。纯本地运行，不调任何外部服务。

## 安装

打开 **Releases → 最新版**，按需下载并解压到任意目录，运行目录中的 `gd-live-tool.exe`：

- `gd-live-tool-vX.Y.Z-full.zip` —— **全量包**（首次安装用）
- `gd-live-tool-vX.Y.Z-diff-from-<旧版本>.zip` —— **增量包**（已装旧版本时用，体积更小；没有对应增量时用全量包即可）

> 建议解压到非系统盘、路径不含中文与空格的目录。首次启动会自动准备所需数据。

## 更新

启动时自动检查更新（约每小时一次），发现新版本弹窗一键更新；也可右键托盘图标 →「检查更新」。

- 更新包按 `manifest.json` **逐文件校验 sha256**，校验不过直接拒收，失败自动回滚
- 数据包走**独立增量通道**，同样自动完成

## 相关

- 面板默认监听 `localhost:8016`，OBS 叠加层也由该服务托管
- 反馈与更新说明见 Releases 各版本的更新说明
